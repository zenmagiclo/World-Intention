# World-Intention
a game about letting a little guy named "Drifter" cross the dimensions.

### Keyboard Controls
up arrow -- shift the world downwards 
down arrow -- shift the world upwards 
left arrow -- shift the world right 
right arrow -- shift the world left 
 
i know these sound weird but just trust me. 
 
R -- Reset the level 

### Mouse Controls
left-click + drag -- grab/move obstacle 
release mouse -- drop obstacle

### Game Controls
enter world -- start game
play again -- restart after win
